## What is Rewrite Labs?

Rewrite Labs is a brand built for engineers who are stuck at the intersection of technical excellence and personal stagnation. The platform combines a newsletter, a book, and a SaaS tool — all designed around one core idea: **your career is code, and it can be rewritten.**

The website serves as the central hub — introducing the philosophy, the community, the book, and the product.

## Design Philosophy

The site uses a **dark terminal aesthetic** — monospace fonts, muted greens and whites on near-black backgrounds, command-line prefixes (`>_`), and structured bento grids. The intent is to feel native to an engineer's world while being visually distinct from typical SaaS landing pages.

Animations are intentionally restrained — entrance transitions and hover states via Framer Motion, no auto-playing videos or heavy media.
